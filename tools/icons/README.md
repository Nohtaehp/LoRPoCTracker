# Card icon supplements

Icons in this folder fill gaps in the game's own card-frame assets and are copied
to the build output (`tools/icons`) by `LoRPoCTracker.csproj`.

- `icon_trap_crispmip.png`: recoloured from the "Mantrap" icon by
  [Lorc](https://lorcblog.blogspot.com) on [game-icons.net](https://game-icons.net/1x1/lorc/mantrap.html),
  licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/).
  Used for the card type "陷阱" (Trap), which has no dedicated in-game speed icon.
